## 1. 这个插件是干什么的？

「科应共享账号助手」是科应共享账号管理平台配套的**浏览器插件（扩展）**，负责四件事：

| 功能 | 说明 |
|---|---|
| 自动绑定 | 你在看板「领取账号」并点「打开科应」后，自动把本次租期和科应页面绑定，无需手动登录 |
| 自动续期 | 你在科应页面**真实点击 / 滚动 / 打字**时，插件会自动上报「正在使用」，租期自动顺延 |
| 租期提醒 | 科应页面右下角出现**倒计时圆环**，随时告诉你还剩多少使用时间 |
| 及时归还 | 用完点一下「立即归还」，把账号让给下一位同事 |

一句话：**不装插件也能浏览看板，但要正常领取账号、自动续期，必须先装好它。**

> 重要前提：本插件仅在你单位的**内网看板**与**科应官网（scienceing.com）**上工作，全程不采集你的任何搜索内容与密码（详见[第 7 节](#7-安全与隐私说明)）。

## 2. 安装前准备（下载与解压）

### 2.1 获取安装包（ZIP 文件）

登录看板后，任选一种方式下载最新版压缩包（文件名形如 `scienceing-extension.zip`，内含扩展程序）：

- **方式 A（推荐）**：看板**顶栏插件图标**（带“下载助手 ZIP”提示）→ 点击自动下载；
- **方式 B**：「我的账号」页面若提示“未检测到助手”→ 点击其中的**「下载助手 ZIP」**链接；
- **方式 C（管理员）**：管理后台 →「系统参数」→「扩展配置」→「下载最新版 ZIP」。

> 浏览器默认把下载文件保存到“下载”文件夹。若不确定下载到哪里，按 `Ctrl + J` 打开浏览器下载列表即可查看。

### 2.2 解压到固定文件夹（关键一步，别跳过）

1. 在电脑上新建一个**固定文件夹**，例如 `C:\ScienceingAssistant`（路径随意，但**不要**建在“下载”临时文件夹里）。
2. 将下载好的 ZIP 右键 → **全部解压缩** → 解压到该文件夹。
3. 解压后请确认：**`manifest.json` 文件直接位于该文件夹内**（而不是“文件夹里还套一层子文件夹”）。
   - ✅ 正确：`C:\ScienceingAssistant\manifest.json`
   - ❌ 错误：`C:\ScienceingAssistant\科应共享账号助手_v1.3.0\manifest.json`

> ⚠️ **三条铁律：**
> 1. **解压后此文件夹要一直保留、不要删除、不要移动、不要改名** —— 插件是以“加载已解压扩展”方式运行的，它随时读取这个文件夹。删除/移动文件夹 = 插件立即失效。
> 2. **不要直接把 ZIP 拖进浏览器** —— Chrome / Edge 已不支持拖拽 ZIP 安装（详见 FAQ [6.2](#62-把-zip-拖进浏览器没反应-或提示无法添加)）。
> 3. 浏览器要求 **Chrome / Edge 102 及以上版本**（近几年安装的浏览器都满足），手机浏览器不支持。

## 3. 方法一：在 Chrome 中安装

1. 打开 Chrome，在**地址栏**输入以下地址后回车，进入扩展管理页：

   ```
   chrome://extensions
   ```

2. 打开页面**右上角**的 **「开发者模式」**开关（会变蓝色）。
   - 此时页面顶部若出现黄色提示“请停用以开发者模式运行的扩展程序”，属正常现象，点“取消”即可，**不用管它**。

3. 点击页面**左上角**的 **「加载已解压的扩展程序」** 按钮。

4. 在弹出的文件夹选择窗口中，**选中你在 [2.2](#22-解压到固定文件夹关键一步别跳过) 里解压好的文件夹**（例如 `C:\ScienceingAssistant`），点击 **「选择文件夹」**。

5. 列表中应出现卡片 **「科应共享账号助手」**（含版本号，如 v1.3.0），且**卡片上没有任何红色报错** —— 安装成功！🎉

> 💡 **失败提示对照：**
> - 若提示 `Manifest file is missing or unreadable`（清单文件缺失或不可读）→ 你选错了文件夹层级，见 FAQ [6.1](#61-加载时报错清单文件缺失或不可读manifest-file-is-missing-or-unreadable)。
> - 若卡片上方有红色小字错误信息 → 把错误提示截图发给管理员协助处理。

## 4. 方法二：在 Edge 中安装

> Edge 的操作与 Chrome 几乎一样，只是按钮叫法略有不同。如果你平时用 Chrome，直接看[第 3 节](#3-方法一在-chrome-中安装)即可。

1. 打开 Edge，在**地址栏**输入以下地址后回车：

   ```
   edge://extensions
   ```

2. 打开页面**左下角**的 **「开发人员模式」**开关。

3. 点击**左上角**的 **「加载解压缩的扩展」** 按钮（注意 Edge 叫“解压缩”，Chrome 叫“已解压”，是同一个意思）。

4. 选中你在 [2.2](#22-解压到固定文件夹关键一步别跳过) 里解压好的文件夹（例如 `C:\ScienceingAssistant`），点击 **「选择文件夹」**。

5. 看到卡片 **「科应共享账号助手」** 且无红色报错即安装成功。

## 5. 安装成功后如何启用并验证

插件装好后**默认已启用**，接下来按下面 5 步做一遍“冒烟测试”，全部通过就可以正常使用了。

### 第 1 步：把插件固定到工具栏（推荐，可选）

Chrome / Edge 右上角有一个 **拼图图标** 🧩（扩展程序列表），点开后找到「科应共享账号助手」，点击其右侧的**图钉 📌**，把它固定到工具栏。
（本插件点击图标本身不会弹出窗口，这属于正常设计，固定只是为了便于随时查看状态。）

### 第 2 步：打开看板，确认插件“就绪”

在浏览器访问你的**科应共享账号看板**（例如 `http://10.3.124.100:18080/`，以管理员分发的地址为准），登录后留意**页面顶部的插件状态条**：

- 显示绿色 **“就绪 / 已连接”** → ✅ 插件与看板握手成功（页面加载后约 3 秒内自动完成）。
- 仍显示“未安装 / 未检测到助手” → 先按 `F5` 刷新页面再看；仍不行则查 FAQ [6.3](#63-插件明明装好了看板仍提示未安装)。

### 第 3 步：领取账号，验证自动打开

1. 进入「我的账号」页，点击 **「领取」**；
2. 点击 **「打开科应」** —— 浏览器应**自动新开一个科应官网（scienceing.com）标签页**并完成绑定。

### 第 4 步：验证右下角悬浮窗

在打开的科应页面上，**右下角**应出现一个**圆形倒计时环**悬浮窗（绿色圆环 + “释放时间”字样）—— 出现即代表绑定成功。

悬浮窗环色含义：

| 颜色 | 含义 | 处理 |
|---|---|---|
| 🟢 绿色 | 剩余时间 5–30 分钟，正常 | 无需操作 |
| 🟡 黄色 | 剩余 1–5 分钟，即将到期 | 继续真实操作会自动续期 |
| 🔴 红色 | 剩余不足 1 分钟 | 会弹窗提醒：点「继续使用」（操作页面续期）或「立即归还」 |
| ⚪ 灰色“已释放” | 租期已结束 | 点悬浮窗「返回看板」重新领取 |
| 🟠 琥珀色“异常” | 与后端连接异常 | 检查是否在内网/可访问看板，稍后自动恢复 |
| ⚪ 灰色“未绑” | 当前未绑定账号 | 回到看板领取账号 |

### 第 5 步：验证自动续期与归还

- **续期**：在科应页面真实地点击、滚动、敲键盘 → 悬浮窗时间会回到“满格”（说明插件成功上报了你的真实操作）。
- **归还**：用完后点击悬浮窗 → 点 **「立即归还」** → 自动跳转看板「我的账号」页确认归还，把账号让给同事。

> ✅ 以上 5 步全部通过，说明插件安装 + 激活完整成功！

## 6. 常见问题排查（FAQ）

### 6.1 加载时报错「清单文件缺失或不可读」（Manifest file is missing or unreadable）

**原因**：你选择的文件夹不是扩展的“根目录”——最常见是 ZIP 解压后**多包了一层文件夹**。
**解决**：打开你解压的文件夹，往里看一层：
- 如果 `manifest.json` 不在当前文件夹、而是在里面的某个子文件夹中，就**改选那个子文件夹**；
- 或者把 ZIP **重新解压一次**，确保最终选中的文件夹里**直接**就能看到 `manifest.json`。
然后再点一次「加载已解压的扩展程序」。

### 6.2 把 ZIP 拖进浏览器没反应，或提示“无法添加”

**原因**：Chrome / Edge 出于安全考虑，**已不支持**把 `.zip` / `.crx` 文件直接拖进扩展页安装。
**解决**：请回到[第 3 节](#3-方法一在-chrome-中安装)或[第 4 节](#4-方法二在-edge-中安装)，按“**开发者模式 → 加载已解压的扩展程序 → 选择解压文件夹**”的流程安装。

### 6.3 插件明明装好了，看板仍提示“未安装”

按顺序排查：

1. **先刷新看板页面**（`F5`）。看板与插件通过“握手”通信，约 3 秒判定，刷新前看到的是旧状态。
2. **确认看板地址正确**。本插件只在你单位内网看板地址（含当前 IP 的域名）上注入。若看板地址有过变更（例如内网 IP 从 `10.3.124.100` 改成别的），**旧安装包无法匹配新地址**，需要联系管理员**重新打包**并重新下载安装（可顺手在扩展页点卡片上的「重新加载」）。
3. **确认没有误删解压文件夹**（见[2.2](#22-解压到固定文件夹关键一步别跳过)铁律①）。文件夹被移动/删除后，插件实际已失效，需重新加载或重装。
4. **若使用“无痕 / InPrivate 窗口”**：Chrome 在 `chrome://extensions` 中点击插件卡片的「详细信息」→ 打开 **「在无痕模式下启用」**；Edge 在 `edge://extensions` 点卡片「详细信息」→ 打开 **「InPrivate 中允许」**。
5. **多账号浏览器用户**：确认当前使用的是当初安装插件的那个浏览器用户（Profile）。

### 6.4 提示“版本过旧 / 需要更新”（outdated）

**原因**：你安装的版本低于后端要求的最低版本。
**解决**：
1. 按[第 2 节](#2-安装前准备下载与解压)重新下载**最新 ZIP**；
2. 解压**覆盖**到原来的文件夹；
3. 到扩展管理页，点击「科应共享账号助手」卡片上的 **「重新加载」**（图标为 ↻）；
4. 回到看板刷新页面，状态应变为就绪。

> 兜底方案：在扩展页把旧插件「移除」，然后重新按[第 3 节](#3-方法一在-chrome-中安装)/[第 4 节](#4-方法二在-edge-中安装)加载一次。

### 6.5 打开科应后，页面右下角没有悬浮窗

1. 确认当前打开的确实是 **`www.scienceing.com`**（插件只在科应官网与看板两个网站工作）；
2. 确认你**已经“领取”账号**（未绑定时无窗或显示灰色“未绑”）；
3. 确认插件**开关处于开启**状态：扩展管理页中该卡片若为灰色，点一下启用；
4. 若以上都正常，按 `F12` 打开开发者工具 → Console 标签，截图报错信息发给管理员。

### 6.6 悬浮窗显示琥珀色“异常”

说明插件暂时连不上内网后端。检查：
- 是否已断开内网 / 不在公司网络；
- 能否正常打开看板页面。
确认网络正常后稍等片刻会自动恢复，也可点击悬浮窗「返回看板」重新触发连接。

### 6.7 红色倒计时弹窗一直提醒，怎么办？

这是“租期即将到期”的正常提醒：
- 还需要继续用 → 点 **「继续使用」**，并在科应页面做一次真实操作即可续期；
- 用完了 → 点 **「立即归还」**，把账号释放给他人。

### 6.8 浏览器一直提示“请停用以开发者模式运行的扩展程序”

**属正常现象**，不必处理。这是浏览器对“手动加载扩展”的统一提示，点“取消”后不影响任何功能。（本插件通过开发者模式分发，属于单位内网协作场景，无法上架到官方商店。）

### 6.9 升级时提示失败 / 想重新安装

先在扩展管理页把旧卡片 **「移除」**（只是从浏览器移除，不影响解压文件夹），确认解压文件夹仍在，再重新执行一次“加载已解压的扩展程序”即可。

### 6.10 公司电脑提示“已被管理员禁用扩展安装”之类

部分企业电脑会通过组策略**禁用开发者模式/手动加载扩展**。请将本文档连同扩展安装包发给 IT / 管理员，由他们评估后统一处理。

### 6.11 换了电脑 / 换了浏览器，需要重新装吗？

需要。新设备只需：下载 ZIP → 解压 → 按[第 3 节](#3-方法一在-chrome-中安装)或[第 4 节](#4-方法二在-edge-中安装)加载一次即可，**无需任何其他配置**。

## 7. 安全与隐私说明

可以放心使用，本插件遵循**最小权限**原则：

- **仅申请 2 项权限**：
  - `tabs` —— 识别“科应页面是从哪个标签页打开的”，用于账号自动绑定与多标签继承；
  - `storage` —— 仅在内存中保存本次租期标识（会话级，**关闭浏览器即清空**）。
- **不申请** `cookies`、`history`、`webRequest` 等任何多余权限；
- **绝不采集**你的搜索词、论文正文、输入内容、Cookie、科应密码或管理员凭据；
- 只有在你**领取账号的使用期间**才工作，平时基本处于待机状态。

## 8. 卸载 / 换电脑重装

**卸载步骤：**

1. Chrome：地址栏输入 `chrome://extensions`；Edge：输入 `edge://extensions`；
2. 找到「科应共享账号助手」卡片；
3. Chrome 点卡片上的 **「移除」**；Edge 点卡片上的 **「删除」**，并在弹窗中确认；
4. （可选）删除第 [2.2](#22-解压到固定文件夹关键一步别跳过) 步创建的文件夹（如 `C:\ScienceingAssistant`）。

**需要恢复**：重新下载 ZIP → 解压 → 再走一次[第 3 节](#3-方法一在-chrome-中安装)/[第 4 节](#4-方法二在-edge-中安装)即可，无需任何额外配置。
